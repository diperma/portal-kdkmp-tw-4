# Repo dan halaman Portal bersifat public; kontrol akses ada di tujuan tautan

Repo `portal-kdkmp-tw-4` dan halaman GitHub Pages-nya bersifat public (syarat GitHub Pages gratis). Portal tidak memuat data apa pun. Kedua aplikasi web yang dituju (`uji-petik-kdkmp-tw-4`, `populasi-kdkmp-tw-4`) mengambil data dari Firestore yang aturan aksesnya hanya mengizinkan akun Google `@bpkp.go.id` terverifikasi; folder Google Drive yang kelak ditambahkan dibatasi di level Drive seperti TW 3.
